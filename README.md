# Acids, pH & Particles Quiz

Multiple-choice revision quiz for Year 10 Chemistry (Willetton SHS, Task 8: acids, bases and rates test).

**Levels**

1. 🔤 Acid & Base Formulas (12 questions)
2. 🌈 pH & Indicators: the pH scale, universal indicator, litmus, neutralisation (14)
3. ⚛️ Particles & Temperature: particle motion, kinetic energy, heating curves (8)
4. 📖 Terminology: flip cards, sometimes the term and sometimes the definition (9)

Questions you get wrong come back at the end of each level until you get them right.

## Use it

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) and use the link on a phone.

The **✏ Teacher** button opens an editor for adding, changing or deleting questions. Edits are saved in that browser only; **Restore defaults** brings the original set back.

## Notes

- Questions are written from the class materials (lessons 10.1–10.8 and the course outline's particle model and Task 8 descriptions).
- Terminology definitions follow the wording in the class slides where there is one.
